# SQL Banking Practice (MySQL)

This project contains SQL practice queries based on a banking-style relational database.

The database models a financial institution with:

- Departments
- Branches
- Employees (with hierarchy)
- Individual and Business customers
- Accounts
- Transactions
- Products

## Database

Schema name: `firm`  
Database system: MySQL

## Project Structure

### schema/
Contains the database creation script.

### queries/
Organized by topic:

- 01_select.sql – Basic SELECT statements
- 02_where.sql – Filtering data
- 03_order_by.sql – Sorting and pagination
- 04_joins.sql – Multi-table joins
- 05_group_by.sql – Aggregations and reporting
- 06_subqueries.sql – Advanced subqueries
- 07_data_modification.sql – INSERT / UPDATE / DELETE
- 08_indexes.sql – Index creation
- 09_views.sql – Views for reporting

## Skills Demonstrated

- Data filtering
- Multi-table joins
- Self joins
- Aggregations with GROUP BY / HAVING
- Correlated subqueries
- Derived tables
- Banking-style analytical queries
- Schema understanding and relational modeling
